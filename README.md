# midterm_sourcefile_repo

Public repository for JavaScript source code and midterm lesson examples.

## Contents

- `Lesson1/` — introductory JavaScript program and notes
- `Lesson2/` — array lecture notes
- `Lesson3/` — array demonstration program
- `Lesson4/` — linked-list program and data structures notes
- `Lesson5/` — array exercise and student analyzer programs
- `Lesson6/` — Week 6 stacks, queues, and linked-list exercise
- `GIT_WORKFLOW.md` — Git command sequence for the activity
- `CONTRIBUTING.md` — guidance for adding more source files

The Lesson 5 sample names use generic labels. Each program is kept in its own file under the lesson where it was developed.
